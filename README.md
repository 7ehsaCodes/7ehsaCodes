## Featured project

### VaultSafe

**A local-first encrypted vault for Windows, built with Python and PySide6.**

VaultSafe combines a native desktop experience with a Chrome / Edge extension. It supports encrypted credentials, secure notes, TOTP, password generation, encrypted backups, attachments, imports and explicit exports — without requiring a remote account or subscription.
